# pgAdmin - Безопасный доступ к PostgreSQL

## ⚠️ БЕЗОПАСНОСТЬ

pgAdmin настроен с **МАКСИМАЛЬНОЙ БЕЗОПАСНОСТЬЮ**:

1. **Порт только на localhost** - недоступен извне (`127.0.0.1:5050`)
2. **Не запускается автоматически** - используется `profiles: ["tools"]`
3. **Доступ только через SSH туннель** - никто кроме вас не подключится
4. **Не перезапускается** - `restart: "no"`

---

## 🚀 Как использовать

### 1. Установить пароль в .env

```bash
# Добавьте в .env на сервере:
PGADMIN_EMAIL=your-email@example.com
PGADMIN_PASSWORD=YourVerySecurePassword123!
```

### 2. Запустить pgAdmin (только когда нужно)

```bash
# На сервере:
cd /opt/music-platform
docker compose --profile tools up -d pgadmin
```

### 3. Создать SSH туннель (на вашем компьютере)

```bash
# Windows (PowerShell):
ssh -L 5050:127.0.0.1:5050 root@188.225.85.65

# Linux/Mac:
ssh -L 5050:127.0.0.1:5050 root@188.225.85.65
```

### 4. Открыть в браузере

После создания SSH туннеля откройте:
```
http://localhost:5050
```

Введите email и пароль из .env

### 5. Подключиться к PostgreSQL

При первом входе нужно ввести пароль PostgreSQL:
- **Пароль**: значение `POSTGRES_PASSWORD` из вашего .env

---

## 🛑 После работы - ОБЯЗАТЕЛЬНО остановить!

```bash
# На сервере:
docker compose --profile tools stop pgadmin
```

Или удалить полностью:
```bash
docker compose --profile tools down pgadmin
```

---

## 🔒 Почему это безопасно?

| Защита | Описание |
|--------|----------|
| `127.0.0.1:5050` | Порт недоступен извне, только localhost |
| SSH туннель | Шифрованное соединение, требует SSH ключ |
| profiles: tools | Не запускается с обычным `docker compose up` |
| restart: no | Не перезапускается автоматически после перезагрузки |
| no-new-privileges | Контейнер не может повышать привилегии |

**Результат**: Даже если кто-то узнает пароль pgAdmin - он НЕ сможет подключиться без SSH доступа к серверу.
